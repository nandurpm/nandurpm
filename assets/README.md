# Profile Assets

## Purpose

Contains versioned visual resources embedded by the public GitHub profile README.

## Contents

- `profile-hero.svg` — Accessible 1200 × 300 engineering-themed banner containing the profile name, role, and focus areas.

## Responsibilities

Store only public, profile-specific visual assets here. Project screenshots and implementation assets belong in their respective repositories, while profile copy and links remain in the root `README.md`.

## Important Notes

Keep SVG title/description text and the README `alt` text aligned with visible banner content. Preserve the current relative path so the image renders on the GitHub profile page, and avoid embedding scripts, external resources, private metadata, or unlicensed content.
